# ADR-0015 — Basic-local complete derived graphs and replay

**Status:** Implementation decision pending PR review. **Date:** 2026-10-14.

`m3-local-graph-v1` binds an explicitly expected SourceAdmission digest, complete source reference, normalized full target/policy/export options, actual runtime artifact set and seven ordered typed nodes: request, M2A, M2B, M2C, M2D, M2E, M2F. Each node has its exact JSON payload string, ordered parents and SHA-256 of the canonical envelope. The only external parent is the source admission; every prior node is explicitly included in subsequent parent lists. Complete outcomes/issues and independent B/C/D verification records are retained; downstream unavailable/disabled states have explicit reasons rather than successful empty results.

Canonical envelope/request encoding uses ADR-0014 native JSON numeric normalization. M2 payloads are exact compact sorted JSON strings preserving float/tuple serialization. Native dataclass admission precedes serialization; positive producer output must pass its independent M2 verifier. No data from persisted model dictionaries is hydrated and fed as trusted authority: reload verifies root/node closure and selectors, checks exact runtime artifacts, re-reads original bytes and regenerates/independently verifies the whole pipeline, then compares the complete manifest byte-for-byte.

An explicit new graph may re-derive from historically admitted raw/source material under current artifacts, even when the original M2A snapshot cannot be verified with those artifacts. This is a new immutable GraphCommit, never a rewrite or verified relabeling of old M2A. Source raw binding is integrity_checked_local; source-and-m2a verification continues to require historical artifact compatibility. Graph status verified_local has scope m2a-m2f with each stage outcome separately exposed.

SQLite schema v2 adds a graph table with immutable manifest BLOB, root digest primary key and source-admission foreign key; transactional v1→v2 is additive, preserves source rows and does not migrate evidence. Source APIs understand v2. Graph publication is one transaction after the complete pipeline is evaluated and verified; source material remains committed if later derivation/size failure occurs. Aggregate manifest cap is 16 MiB and stored manifest length is checked before allocation. This does not complete all F6 observation/complexity/time/RSS limits or task orchestration.

Query returns candidate identities only, not a trusted best match. Reload requires explicit graph digest, expected source digest and full target/policy/options. Multiple policies/areas from one source are separate results, not ambiguous automatic selection. Same inputs/artifacts repeat idempotently; changed artifacts produce a new commit. Historical mismatch returns historical_unverified with no verified output. Basic mode remains trusted-local, not malicious-storage authentication; enhanced finality is still unavailable.
