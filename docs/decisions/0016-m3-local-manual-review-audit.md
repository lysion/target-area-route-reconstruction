# ADR-0016 — Local append-only manual review streams

**Status:** Implementation decision pending PR review. **Date:** 2026-10-14.

Implements ADR-0009 in basic-local. Explicit opt-in `LocalReviewStore` migrates SQLite v2→v3 transactionally, adding only a review table; source and graph APIs understand v3 without implicitly creating review storage. No core schema or M2 identity changes.

Each review stream is scoped to an exact GraphCommit and a caller-supplied task scope. Admission and effective-result projection require fresh `reload_graph` with all explicit selectors and verified_local status, plus an available M2D assessment. Records bind that assessment id/revision and graph digest, stable caller decision_id, actor, reason, canonical UTC timestamp (`YYYY-MM-DDTHH:MM:SS.ffffffZ`), action (`set` or `revoke`), relation and predecessor digest. Timestamp is claimed provenance, not trusted clock or ordering authority. Order is the serialized predecessor chain. Actor is recorded provenance, not authentication.

`m3-local-review-v1` canonical native JSON records are SHA-256 addressed. A transaction checks the caller's explicit expected head (None only for a new stream), verifies the complete existing stream, and appends once. Exact idempotent retries return the original record, even after later decisions; reused decision_id with different content conflicts. Concurrent corrections with the same predecessor cannot both succeed. A revoke requires the current head to be a set; it retains every previous fact and restores algorithmic relation. Later set may follow a revoke. Multiple scopes never compete for precedence. No cross-graph review inheritance or automatic latest selection.

Read requires the externally expected current head, including explicit None for no decisions. It verifies canonical bytes, hashes, exact fields/types, assessment binding and every predecessor/action before projecting. Only the final head applies. Projection exposes algorithmic relation, effective task-facing relation and full audit JSON. SpatialAssessment, completeness, segments, source, geometry and metrics remain untouched. Unavailable graph artifacts never yield an effective verified projection.

SQLite commit atomically appends each fact; pre-commit crash leaves no decision, post-commit retry is idempotent. Each record is capped at 64 KiB and each stream at 10,000 entries; oversized stored records are refused before fetching their BLOB. These are local review bounds, not completion of F6 processing budgets. Basic-local cannot authenticate coherent hostile replacement/rollback, actor identity or timestamp. Enhanced custody remains unavailable. General task scheduling, backup/recovery administration, quarantine and F6 exit gates remain separate work.
